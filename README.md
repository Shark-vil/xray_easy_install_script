# XVEI — a simple Xray server setup manager

Installs [Xray](https://github.com/XTLS/Xray-core) on a Linux server and lets
you change its setup from a menu: connection types, WARP / TOR and other
servers as a second hop, routing rules, the website on your domain, backups and
rollback.

📖 **Documentation:** <https://shark-vil.github.io/xray_easy_install_script/>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Shark-vil/xray_easy_install_script/master/xvei.sh) install
```

Ubuntu 20.04+, Debian 11+, CentOS Stream 9; run as root.
